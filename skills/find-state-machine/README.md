# find-state-machine

Find the state machines an app already has but never declared: the flags,
booleans, status strings, and enums that together encode a lifecycle.

## Use it with a prompt

- "find all of the implicit state machines in my app"

That is the whole instruction. How to answer it is left to the agent, against
the app in front of it.
