# bro

Restate the last message so it can be followed. When a message comes out dense,
skips steps, or leans on terms nobody explained, bro says the same thing the way
one human talks to another.

## When it applies

Use whenever the last message needs a plain-language pass.

## What it produces

A restatement of the last message, not a summary or a new answer. It names the
problem first, keeps the real names from the code or the UI and explains each
one, and puts back the steps the first version skipped. It may be longer than
the original.

See `SKILL.md` for the full contract.
